# Shortly

Shortly is a URL shortener built with the MERN stack (MongoDB, Express.js, React.js, Node.js) that offers detailed analytics on link clicks and engagement.

## Features

- **URL Shortening**: Easily shorten any URL.
- **Analytics**: Track clicks and engagement in real-time.
- **MERN Stack**: Utilizes MongoDB, Express.js, React.js, and Node.js for a seamless experience.
